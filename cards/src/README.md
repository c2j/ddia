# DDIA 权衡卡原型 · 第 5 章（复制）

这是"权衡地图"PWA 的内容样例，共 10 张卡，覆盖三种卡片类型：

- `P-` 困境卡（6 张）：先给场景和约束，不给选项；自己想方案后再揭示代价
- `S-` 推演卡（2 张）：给故障/运行序列，逐步推演系统行为
- `I-` 事故档案卡（2 张）：真实事故叙事，作为记忆钩子

对应原书章节：
- §5.1 领导者与追随者
- §5.2 复制滞后问题
- §5.3 多主复制
- §5.4 无主复制

目的：在写任何代码之前，先验证卡片的内容粒度和措辞。请在手机上读，
感受每张卡是否"只看问题就有想回答的冲动"，揭示部分是否"推翻了你以为的显然答案"。
